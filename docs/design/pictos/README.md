# Pictogrammes gravés

Onze pictogrammes au trait, pour les médaillons des panneaux et des modules (DESIGN.md §4.11). Grille 24 × 24, trait 1,5 px, bouts et angles arrondis, `stroke="currentColor"` : la couleur vient du contexte. Dessinés pour ce projet.

| Fichier | Lieu | Dessin |
|---|---|---|
| `compagnon.svg` | panneau du Compagnon | compas |
| `manuscrit.svg` | tiroir du manuscrit | livre ouvert |
| `entretien.svg` | page Entretien (en bleu : c'est le Compagnon qui parle) | bulle |
| `reglages.svg` | vue Réglages de l'app (`⌘,`) | deux curseurs |
| `carnet.svg` | page Carnet (en bleu : la mémoire du Compagnon) | carnet fermé par son élastique, deux lignes d'écriture |
| `projet.svg` | module Le projet | plan |
| `personnages.svg` | module Personnages | buste |
| `structure.svg` | module Structure | ferme de charpente |
| `regles.svg` | module Règles du monde | fil à plomb |
| `indices.svg` | module Indices et révélations | loupe |
| `diapason.svg` | module Style et voix (« donner le ton ») | diapason |

À part, **`equerre.svg`** : la marque du système du X250 (segment `système`, titre des réglages du système, moniteur), en aplat et non au trait. C'est la forme de l'icône de l'app ([`../icon/charpentier-petit.svg`](../icon/charpentier-petit.svg)) : l'équerre en `currentColor`, le point en bleu du Compagnon de la matière du système (`#86aedb`). 13 px dans la ligne, 14 px dans les titres.

Tailles d'usage : 19 px dans un médaillon de 34 px (titre de panneau), 17 px dans un médaillon de 30 px (rail de l'Atelier). Jamais seuls : toujours à côté de leur libellé.
